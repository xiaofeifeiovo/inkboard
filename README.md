# Inkboard（原型）

轻量的 macOS 手写白板：纯 AppKit + Core Graphics，没有第三方依赖。

## 运行

```bash
scripts/build.sh            # 编译并打包 build/Inkboard.app
open build/Inkboard.app
scripts/build.sh check      # 编译 + 跑核心逻辑自检，并输出 build/sample.png 和 build/sample.pdf
```

开发时也可以直接 `swift run Inkboard`（不打包 .app），自检可以用 `swift run InkboardCheck`。

## 功能

| 工具 | 快捷键 | 说明 |
|---|---|---|
| 钢笔 | P | 黑色，支持压感，三档笔宽 |
| 橡皮擦 | E | 按笔迹局部擦除，会把笔画切成两段；数位笔翻过来用橡皮头时自动切换 |
| 套索选择 | L | 圈选（笔画或图片有一半以上在圈内就算选中），点一下选中单条笔画或一张图片；拖动框内可移动，⌫ 删除，Esc 取消 |
| 插入空间 | S | 在某一高度按下后向下拖，会把这条线以下的内容整体下移；往上拖则删除空白（不会越过这条线） |

- 撤销 / 重做：⌘Z / ⇧⌘Z
- 缩放：触控板双指捏合，或 ⌘= / ⌘- / ⌘0
- 平移：双指滚动，或按住空格拖动
- 画布向右、向下自动扩展
- 显示 → 显示点格：开关点格背景（所有窗口共用，会记住）。导出的 PNG / PDF 和发给 AI 的图片始终是纯白底，不带点格
- 显示 → 显示分块：显示自动分块的结果（段落、公式、图、贴图，按阅读顺序编号）和全局转换会发送的页面，用来检查分块效果
- 文件 → 导出 PNG…（⇧⌘E）/ 导出 PDF…（⌥⇧⌘E），有选区时只导出选区

### 图片

- 放入图片：⌘V 粘贴（截图、从浏览器或其他应用拷贝的图片、在访达里拷贝的图片文件），把图片或图片文件拖到画布上，或者「编辑 → 插入图片…」。可以一次放入多张。
- 图片按原始大小放入（Retina 截图就是屏幕上看到的大小），太大时缩小到窗口可见区域以内；放入后自动选中并切换到套索工具，可以马上拖动。
- 图片在所有笔迹下面，可以直接在图片上书写批注。
- 选中单张图片时四角有手柄，拖动手柄按比例缩放；⌫ 删除；橡皮擦不会擦掉图片。插入空间会把下方的图片一起推开。
- 图片保存在 `.inkboard` 文件里。PNG、JPEG 原样保存；其他格式（如剪贴板上的 TIFF、HEIC）会转成 PNG 或 JPEG，长边超过 4096 像素的会缩小。
- 局部转换只识别方框里的笔迹；全局转换会把贴图连同上面的批注一起发给 AI，由 AI 用一句话概括。

### 导出 PDF

- A4 纵向，笔迹是矢量的（放大不会模糊），图片嵌入在内。
- 分页方式和全局转换相同：按块装页，一段文字、一个公式、一张图不会被切到两页（只有长过一页的段落会在两行之间拆开）；所有页使用同一比例并左对齐，特别高的图单独一页并缩小。

### 文件

每个手绘文件是一个 `.inkboard` 文件，一个文件一个窗口。基于 macOS 原生的文稿机制（NSDocument）：

| 操作 | 快捷键 |
|---|---|
| 新建 | ⌘N |
| 打开… | ⌘O |
| 存储… | ⌘S（第一次存储时选择位置和文件名） |
| 复制 / 存储为… | ⇧⌘S / ⌥⇧⌘S |
| 关闭 | ⌘W |

- **自动存储**：已存储过的文件，修改后会自动写回原文件；未命名的文件由系统暂存，下次启动时恢复。
- 文件菜单里还有「打开最近使用」「重新命名…」「移到…」「复原到 → 上次存储的版本 / 浏览所有版本…」；点窗口标题也可以重命名或移动文件。
- 关闭有未存储内容的未命名文件时，会询问是否存储。
- 运行过一次 `scripts/build.sh` 之后，在访达里双击 `.inkboard` 文件就会用 Inkboard 打开。
- 文件格式是 JSON（`{"version":2,"strokes":[{"id","width","points":[x,y,压力,…]}],"images":[{"id","frame":[x,y,宽,高],"data":"<base64>"}]}`），读写代码在 `InkboardCore/BoardStore.swift`。没有图片的旧文件（version 1）照常打开。损坏或格式不对的文件会提示无法打开。

**从旧版本迁移**：加入文件功能之前，应用只有一块画板，保存在 `~/Library/Application Support/Inkboard/board.json`。升级后第一次启动时，这块画板会作为一个未命名文件打开，按 ⌘S 存到想要的位置即可。旧文件会改名为 `board.imported.json` 保留下来，不会删除。

### 压感

- 数位板（Wacom 等）、随航（Sidecar）上的 Apple Pencil：直接读取 `NSEvent.pressure`
- Force Touch 触控板：按下拖动时读取按压力度
- 普通鼠标：固定中等粗细

笔迹处理：先用向心 Catmull-Rom 样条平滑，再按约 1 屏幕像素的间距重新采样。每个采样点按压力换算成半径，笔画由圆和相邻圆之间的外切梯形拼成，最后一次性填充，所以急转弯处也不会出现破洞。

## AI 转换

两种调用方式，在设置里选：

- **ACP agent**：通过 [ACP（Agent Client Protocol）](https://agentclientprotocol.com) 调用本机的 AI agent，默认是 Antigravity 的 `agy acp`（需要先在终端用 `agy` 登录）。
- **OpenAI 兼容 API**：填写 Base URL、API Key 和模型，直接调用 API。OpenAI、Gemini（Google 提供的 OpenAI 兼容地址）、通义千问、DeepSeek、OpenRouter、本地 Ollama 等都支持这种格式。模型需要支持图片输入。

| 功能 | 入口 | 说明 |
|---|---|---|
| 局部转换 | 工具栏「局部转换」，或「转换」菜单 ⇧⌘L | 在画布上拖出一个方框框住公式，松开后自动识别，LaTeX 代码复制到剪贴板。可以接着框下一个；Esc 或切换工具退出 |
| 全局转换 | 工具栏「全局转换」，或「转换」菜单 ⇧⌘M | 把整个画板分块、装成若干页图片发给 AI，整理成 Markdown，存为与 `.inkboard` 同一文件夹下的同名 `.md`。未存储的文稿会先要求存储；同名文件已存在时询问是否替换 |
| 识别分块类型 / AI 识别分块 | 「转换」菜单 | 本地计算模式下为「识别分块类型」：让 AI 判断每行是文字还是公式、每块图形是手绘图还是示意图；AI 辅助模式下为「AI 识别分块」：让 AI 把各行和图形重新分组成块并标出类型。结果都存进文稿（可在「显示 → 显示分块」查看），可以撤销 |
| 自动检查 | 工具栏「自动检查」，或「转换 → 自动检查」 | 书写时自动检查写完的块，用红框 / 黄框标出错误并给出说明（详见下方「自动检查」） |

分页方式：

1. **分块**：先把画板分成一个个块：一段文字、一个单独的公式、一张手绘图或示意图、一张贴图（贴图上有墨迹时，图和墨迹是一个整体）。按从上往下、同一高度从左往右的顺序排列，图注紧跟在它的图后面。
2. **装页**：按顺序把块装进接近 A4 比例的页面，块不会被切开；一段文字长过一页时在两行之间拆开，特别大的图单独一页。每页只画属于这一页的块。

**分块方式**（设置 → 分块）：

- **本地计算**（默认）：完全在本机根据笔迹几何位置分块。同一行里离得较远的片段（比如略远一点的等号）会自动连成一行，并避开跨栏空白和中间的图形；较高的开放数学符号（如积分号 ∫、竖线 |、括号、根号等）和分数线、等号都会被归入所在行并识别为公式；对上下行距更敏感，容易区分相邻段落或独立公式。需要纠正类型时，可用「转换 → 识别分块类型」让 AI 判断（一段里夹着的公式行会单独成块），改动笔迹后对应位置的识别结果自动失效。
- **AI 辅助**：书写时仍在本机实时分块；需要时选择「转换 → AI 识别分块」，让 AI 根据页面图像重新把各行和图形合并成块（如多行推导、段落、带标注的图等）并标出类型，结果随文稿保存，在「显示 → 显示分块」中带「· AI」标记。之后新写的笔迹仍按几何分块，写到已有组旁边时会自动并入。开启「自动检查」时，若画板上有尚未经过 AI 分组的笔迹，会先做一次「AI 识别分块」（可取消，取消则不开启；失败时会提示并改用本地分块继续）。**注意**：AI 辅助会额外消耗 AI 请求（使用全局转换的模型和思考档位）。
- **专用墨迹分块模型（即将支持）**：预留选项，目前在设置里为灰色不可选。

**设置**（Inkboard → 设置…，⌘,）：

- 方式：ACP agent 或 OpenAI 兼容 API。
- ACP agent：命令和参数。默认 `agy` + `acp`；也可以换成其他支持 ACP 的 agent，例如 `gemini` + `--experimental-acp`。命令可以写名字（会在 `~/.local/bin`、`/opt/homebrew/bin` 等位置查找）或完整路径。
- OpenAI 兼容 API：Base URL（例如 `https://api.openai.com/v1`）和 API Key。API Key 存在系统钥匙串里；重新编译应用后，第一次读取时系统可能会询问是否允许。
- 局部转换和全局转换分别设置模型、思考档位和提示词（识别分块类型和 AI 识别分块都使用全局转换的模型和思考档位）；自动检查可以单独设置模型和思考档位，默认「与全局转换相同」（思考档位也会跟随全局转换）。两种方式各记一套模型选择。模型列表从 agent 或 API 读取，点「读取模型列表」刷新；列表里没有的模型可以用「其他模型…」填写。使用 API 时，思考档位会作为 `reasoning_effort` 发送，不支持这个参数的模型请保持「默认」。
- 全局转换时单张图片的最长边（像素）。
- 分块方式：本地计算 / AI 辅助 / 专用墨迹分块模型（即将支持）。

说明：

- agent 进程在第一次用到时启动，之后一直保留，每次转换开一个新会话。冷启动后第一次请求比较慢（十几秒），之后公式识别一般在几秒内完成。
- Inkboard 不给 agent 文件读写和终端权限，它请求权限时一律拒绝；`.md` 文件由 Inkboard 自己写。
- agy 是编程 agent，每次请求都会附带它自己约 1 万 token 的系统提示，消耗的是你账号的额度。

### 自动检查

书写时把写完的块发给 AI，结合前面的笔记内容检查错误，并在画布上标出：

- **开关**：点工具栏「自动检查」按钮的主体，或选择菜单「转换 → 自动检查」。默认关闭，开关状态按文稿记住。按钮图标显示状态（关闭、已打开、正在检查、检查失败）。
  - 点按钮右侧的箭头打开下拉菜单，查看正在检查、排队中和正在书写的块，以及失败信息和「重试」；点其中一个块，画布会滚动到它并短暂高亮。
  - 打开开关时，会先把开放页上还没检查过和改过的块全部检查一遍（已固定页里没检查过的内容不会自动检查）。如果分块方式设为「AI 辅助」且有笔迹尚未经 AI 分组，会先运行一次「AI 识别分块」（可取消）。
  - **打开一个开关本就开着的文稿时，不会自动全量检查**（避免打开文件就消耗额度）；之后新写的块照常检查，未检查的块可以手动点「检查」。
  - 关闭开关会停止进行中的请求、清空队列并隐藏所有标注，但保留已存的检查结果。
- **什么时候会发请求**：
  - **写完一个块**：开始在另一个块里书写时，上一个写完的块会自动排队检查（不按停笔时间触发；一次只发一个请求）。书写中如果一块被拆开，留下的部分算写完，会立即检查。
  - **接着写**：如果写完的块只是在最近一次发送的块基础上继续变大（已检查的笔画一笔没少），或书写时几个已检查的块合并成了一块，会自动重新检查。
  - **分组变化**：执行「AI 识别分块」（或撤销/重做它）或切换分块方式后，开放页上原本已检查且未改过笔迹、仅因分组变化被合并或拆开的块会自动重新检查。
  - **换页**：写完的块落到下一页时，会先转写并固定当前页（页上还有没检查过的块时一起检查），再开新对话检查这个块。当前页上还有正在写的块时，不会换页。
  - **手动检查**：还没检查过、没在排队、也不是正在书写的块右下角有小的「检查」按钮；正在写的块可以按 ⇧⌘K（「转换 → 检查最新的块」，工具栏下拉菜单里也有）检查。
  - **修改过的块不会自动重发**：擦掉、移动或回到前面的块补充内容后，需要点「重新检查」才会发送。修改已固定页里的块并点「重新检查」时，会重查并重新转写这一页，再用纯文字重判后面已检查的块。
  - 贴图本身不检查；贴图上的手写批注会连同底图作为上下文一起检查。

**画布上看到什么**（开关关闭时什么都不显示；一个块有多个问题时按最严重的标色）：

| 标注 / 标记 | 含义 |
|---|---|
| 红框 | 严重错误，会影响后续推导（如公式写错、定义错误） |
| 黄框 | 描述不准确但不算严重（如漏写下标） |
| 灰色虚线框 | 原来有红框或黄框的块被修改过，等待重新检查 |
| 无框 | 没有问题、已忽视，或尚未检查 |
| 「检查」 | 未检查、未排队、也不是正在书写的块（例如重新打开的文稿里）右下角显示小的「检查」按钮 |

排队、正在检查和正在书写的块在画布上不显示任何标记，以免干扰阅读，它们列在工具栏按钮的下拉菜单里；已有红框 / 黄框的块重新检查时保留原来的框。

红框和黄框右下角有三个按钮：

- **详情**：展开显示每个问题的严重程度、摘要、详细说明和 AI 读到的内容（方便核对是否认错字）；如果问题与前面某个块有关，会在画布上同时高亮该块。
- **忽视**：隐藏这个块的标注框（不可撤销；重新检查后会清除）。
- **重新检查**：把这个块重新发给 AI 判断。原来无框或已忽视的块被修改后，也会在右下角显示「重新检查」（正在往块里继续写、没有擦掉已检查内容时什么都不显示）。

**出错处理、保存与省额度**：

- 出错时不会弹窗：画布上方显示错误提示和「重试」，工具栏图标变为警告标志；队列暂停，直到点「重试」（画布提示条或工具栏下拉菜单里都有）或手动点某个块的「检查」/「重新检查」。
- 检查结果、已固定页的转写、忽视状态和开关状态都随 `.inkboard` 文稿保存（不进撤销栈，按 ⌘Z 不会撤销检查结果或忽视），重新打开文件不用再检查一遍。
- **全局转换复用**：执行「全局转换」时，从第一页起连续且未改动的已固定页会直接沿用存下的转写，只把其余部分发给 AI（全部可复用时不发请求）。
- **省额度**：在「设置」（⌘,）里可以为自动检查单独选择更快、更便宜的模型和思考档位（默认「与全局转换相同」）。自动检查请求较频繁，推荐使用 **OpenAI 兼容 API**（ACP agent 每次新建页会话都会附带较长的系统提示，延迟和消耗都更高）；不需要实时检查时可先关闭开关，写完后再打开按页检查，或只对需要的块手动点「检查」。
